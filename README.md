# 🌿 Cactus House – Backend

This is the **backend** of the "Cactus House" full-stack web application, built with **NestJS**, **TypeScript**, and **MySQL**. It provides RESTful APIs for frontend consumption and supports features such as authentication, product management, order management, user management, chatbot integration with OpenAI, and image uploading to AWS S3.

👉 Frontend Repo: [Cactus House – Frontend](https://github.com/ThimiraMadusanka/cactus-house-web.git)

## 📦 Features

### 🔐 Auth
- Register, login, password reset (JWT-based).

### 🛍️ User APIs
- Manage profile.
- View products.
- Add to cart, view cart, remove from cart.
- Place and manage orders.

### 🧑‍💼 Admin APIs
- Full CRUD for products, orders, users, and contacts.
- Dashboard analytics endpoints.
- Upload OpenAI prompt content for admin.
- Change user statuses, remove users and reset passwords.

### 🧠 AI & Media
- Integrate OpenAI API for chatbot responses.
- Upload plant images to **AWS S3**.

## 🛠️ Tech Stack

- **Framework:** [NestJS](https://nestjs.com/)
- **Language:** TypeScript
- **Database:** MySQL
- **Authentication:** JWT
- **Cloud Services:** AWS S3 (for image upload)
- **AI:** OpenAI API

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/cactus-backend.git
cd cactus-backend
npm install
npm run start:dev

```
